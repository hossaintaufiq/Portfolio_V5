## For developers (running this site locally)

This repository is a **Next.js 16** + **TypeScript** + **Tailwind CSS** portfolio. Content is data-driven under `data/`.

```bash
npm install
npm run dev      # http://localhost:3000  (Webpack)
npm run build
npm run start
```

| Path | Purpose |
| --- | --- |
| `data/*.ts` | Profile, projects, experience, skills, research, education |
| `components/sections/` | Page sections |
| `public/Resume.pdf` | Downloadable resume |

Windows note: scripts use `--webpack` to avoid Turbopack native issues on some setups.
